Workspace, Compute, Notebooks,  DBFS,  Catálogos, Spark

### Conceitos essenciais pro Módulo 1 (foco agora)

Do texto, o que realmente conecta com "Workspace e Compute":

- Data Intelligence Platform / Lakehouse - a ideia central: Databricks é uma plataforma unificada e aberta de analytics para construir, implantar, compartilhar e manter soluções de dados, analytics e IA em escala empresarial. Isso dá o "porquê" antes do "como".
- Lakehouse combina data warehouse + data lake - o data lakehouse combina data warehouses e data lakes empresariais para acelerar, simplificar e unificar soluções de dados, servindo como fonte única de verdade para engenheiros, cientistas de dados e analistas.
- SQL Warehouse (compute gerenciado) - administradores configuram clusters de compute escaláveis como SQL warehouses, para que usuários finais rodem consultas sem gerenciar a complexidade da nuvem. É a base do que já está no README do Módulo 1.
- Notebooks multi-linguagem - notebooks suportam Python, R e Scala além de SQL, e permitem embutir visualizações junto com links, imagens e comentários escritos em markdown.
