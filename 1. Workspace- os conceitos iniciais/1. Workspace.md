## 1. Workspace - conceitos iniciais

O Workspace é o ambiente onde você organiza tudo no Databricks: notebooks, pastas, dashboards, jobs.

Antes de mais nada, faça sua conta na [Databricks Free Edition](https://docs.databricks.com/aws/en/getting-started/free-edition).
### Estrutura básica ao entrar:

- Workspace (menu lateral) → pastas e notebooks, tipo um "Google Drive" do Databricks.
- Catalog → onde ficam os dados (catalogs, schemas, tabelas, volumes) - [Unity Catalog](https://docs.databricks.com/aws/en/data-governance/unity-catalog/).
- Compute → onde você liga/desliga o cluster (a máquina que roda seu código).
- Workflows → agendamento de jobs/pipelines (não precisa agora).
- SQL / Dashboards → área de consultas SQL e criação de dashboards.

⚠️ Antes de rodar qualquer notebook, você precisa de um cluster ligado (ou um SQL Warehouse, se for só SQL). Sem compute, nada roda.

### Passo prático

1. Vá em **Compute** → **Create compute** → crie um cluster simples (ou use **Serverless**, que é a forma mais rápida de começar).
2. Vá em **Workspace** → **Users** → **seu e-mail** → **Create** → **Notebook**.
